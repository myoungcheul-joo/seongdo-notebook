# Seongdo Notebook (성도수첩)

One small notebook for a believer's daily life of faith: **prayer**, **thanksgiving**, **evangelism contacts** and a **daily Bible reading plan** (four passages a day, the McCheyne plan). Everything is saved as plain Markdown notes in your own vault. The plugin makes no network requests and uses no AI.

> Source is viewable, but this is not open-source software. Free to install and use for personal, church and non-profit purposes. See [LICENSE](LICENSE).

## What it does

- **Prayer**: add prayer requests, flip through them one card at a time in prayer mode, and record the answer when it comes.
- **Thanksgiving**: write a few things you are thankful for each day; a daily goal and a streak keep you going.
- **Evangelism**: record only *who you were in touch with* (date, name, method, a one-line note). There are no stages, targets or contact details, on purpose.
- **Bible reading**: the 365-day McCheyne reading plan is built in. Tick off each of the four daily passages and see your streak. If the [Bible Translation Compare](https://github.com/myoungcheul-joo/bible-translation-compare) plugin is enabled, tapping a passage opens it there.
- Works on desktop and mobile. Notes live in one folder (default `성도수첩`), which you can change in settings.

## Privacy

Your records stay in your vault. Nothing is sent to the internet or to any AI service. If you use it on a phone, set a screen lock.

## Install

Settings → Community plugins → search "Seongdo Notebook". Manual install: copy `main.js`, `manifest.json` and `styles.css` from the latest release into `.obsidian/plugins/seongdo-notebook/`.

The interface is in Korean. The Korean guide below explains each notebook.

## 한국어 안내 — 성도수첩

성도를 위한 수첩 하나입니다. 왼쪽 리본의 책 모양 아이콘을 누르면 네 가지 수첩이 열립니다.

- 🙏 **기도** — 「＋ 새 기도제목」으로 적고, 「🙏 기도 모드」로 한 장씩 넘기며 기도합니다. 응답을 받으면 「✅ 응답 기록」.
- ☀️ **감사** — 하루 다섯 가지를 적어 보세요. 연속 일수가 쌓입니다.
- 👣 **전도** — 내가 누구와 접촉했는지만 적습니다(날짜·이름·방법·한 줄 메모). 연락처·주소·민감한 사정은 적지 마세요.
- 📖 **성경읽기** — 맥체인 읽기표(하루 네 본문). 본문 이름을 누르면 「역본대조」 플러그인이 있을 때 성경 본문이 열리고, 읽은 뒤 칸을 체크합니다.

기록은 모두 내 볼트 안의 마크다운 노트에만 남습니다. 인터넷이나 AI로 보내지 않습니다. 휴대폰에는 잠금을 꼭 걸어 두세요.
